## 5. New findings from this part

1. **Duplicate meta description on every page.** `index.html` still carries a static `<meta name="description">`, so each route ends up with **two** description tags — the static one first, the sheet's one second. A crawler may pick the static one, which would undo this part's meta work. Needs `index.html` edited (site-wide, so I did not touch it without your OK). Verified directly in the page head.
2. **The site is client-side rendered.** Helmet writes the title/meta only after JavaScript runs. Google renders JS, but social scrapers and non-JS crawlers see the static tags. Prerendering/SSR is the real fix — a later part.
3. **Helmet is currently the only thing giving pages their own titles**, and it works — but note the `<title>`/meta only appear once the page is visible (Helmet commits via `requestAnimationFrame`). Not a bug, just worth knowing when testing.
4. **"Address and Map" has no map.** There is no verified location link or coordinates, so I added the heading and the address text but no embedded map. Give me the Google Maps link (or confirm coordinates) and I'll add it.
5. **"Case Studies" on Home is a policy statement, not case studies.** There are no real case studies yet, so the section states that only verified work is published. Replace it with real studies when you have them.
6. Still outstanding from Part 1: footer links to `/privacy` and `/terms` (both 404), and all 5 footer social icons are `href="#"`.
7. `Contact.jsx` now needs `Link` — it never imported `react-router-dom` before, because no link existed on that page. Added.
